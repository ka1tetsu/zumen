# クロスけいさん機

内装の図面から、**壁紙(クロス)が何ロール必要か**を出す道具です。
スマホで図面の写真を撮るだけで、ロール数と発注メモが出ます。

- 文字が大きく、ボタンが大きく、画面はいつも1つだけ。**老眼でも、手袋でも使えます**
- 結果は**声でも読み上げ**ます
- 職人が面倒だと言う **飾り棚(ニッチ)** と **間接照明(コーブ)** を、展開して取り都合まで計算します
- 電波がなくても、計算だけはオフラインで動きます(写真の読み取りだけ通信が必要)

## つかいかた(現場の人向け)

1. ブラウザでアプリを開く(下の「動かしかた」で出てくるアドレス)
2. スマホなら **ホーム画面に追加** しておく。アプリのように開けます
3. 画面のとおりに進む

| ボタン | すること |
|---|---|
| **しゃしんで はかる** | 図面を撮る → よみとる → 数字を確かめる |
| **じぶんで いれる** | 横幅と高さを、大きなボタンで入れる |
| **けいさん する** | ロール数が大きく出る。読み上げ・コピー・印刷ができる |

写真から読んだ数字には、**よめた / たぶん / 要かくにん** の札がつきます。
**要かくにん**(赤)は、図面から読み取れなかったところです。必ず手で直してください。

### 飾り棚(ニッチ)

開口の **よこはば・たかさ・おくゆき** の3つを入れるだけです。
奥・上・下・左・右の5面を展開して、材料の幅の中に並べ直し、
「何 m 切れば足りるか」を出します。張らない面は外せます。
入隅・出隅の数も出るので、手間を乗せるときの目安にしてください。

### 間接照明(コーブ照明)

**ながさ** と、**たちあがり + そこ + みつけ**(図が出ます)を入れます。
展開幅の帯が材料の幅から何本取れるかを計算するので、
「5m の照明に 5m のクロス」ではなく、**実際に要る 1.8m** が出ます。

## 動かしかた

```bash
npm install
npm start            # → http://localhost:8787
```

写真の読み取りを使うときは、Claude の API キーを渡してください。
**キーはサーバーの中だけに置きます。スマホやブラウザには渡りません。**

```bash
ANTHROPIC_API_KEY=sk-ant-... npm start
```

キーが無くても起動します。その場合は「じぶんで いれる」で全部使えます。

同じ Wi-Fi のスマホから使うときは、パソコンの IP を見て
`http://192.168.x.x:8787` を開いてください。

### 写真を使わないなら、サーバーもいりません

`public/` の中だけで動きます。静的なホスティング(GitHub Pages など)に
そのまま置いても、手入力の計算・保存・印刷・読み上げは全部動きます。

### 設定

| 環境変数 | 既定 | なに |
|---|---|---|
| `PORT` | 8787 | 待ち受けるポート |
| `ANTHROPIC_API_KEY` | (なし) | 写真の読み取りに使う。無ければ読み取りだけ止まる |
| `KUROSU_MODEL` | `claude-opus-5` | 読み取りに使うモデル |

## 中身

```
public/          スマホで開く画面(そのまま静的配信できる)
  engine.js      ← 計算はぜんぶここ。DOM を触らない純粋な関数だけ
  app.js         画面の組み立て
  style.css      大きい文字・大きいボタン・印刷用の体裁
  sw.js          オフライン用
server/
  index.mjs      public/ を配る + /api/read-drawing
  prompt.mjs     図面を読ませるときの指示と、報告用の道具(tool)の形
  takeoff.mjs    送られた写真の検査と、AI の答えの整形
test/            node --test で動く。計算の根拠を全部テストにしてある
docs/keisan.md   計算のしかた(職人さん向け・全部の根拠)
```

```bash
npm test         # 27 件
```

## 数字の根拠

既定値は「国産クロス 幅92cm / 50m巻、重ねしろ 20mm、上下の切りしろ 100mm、予備 5%」です。
どうやってロール数まで持っていくかは **[docs/keisan.md](docs/keisan.md)** に全部書いてあります。
現場のやり方に合わせて、**せってい**画面から変えられます。

のり・ジョイントコークの量は目安です。メーカーと現場で変わります。

## 気をつけること

- **AI は図面を読み違えます。** 数字は必ず職人の目で確かめてください。
  このアプリは、読めなかったところを 0 のままにして警告を出します。黙って埋めません。
- ロール数は予備を乗せた切り上げです。柄物・斜め張り・大きな柄合わせは、別に見てください。
