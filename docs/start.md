# つかいはじめ

「どうやって使うの?」の答えです。目的に合わせて、どれか1つを選んでください。

---

## A. とりあえず今すぐ試す(パソコン1台、5分)

パソコンで動かして、同じ Wi-Fi のスマホから見る方法です。事務所の中だけで使えます。

```bash
npm start
```

出てきた `http://localhost:8787` をパソコンのブラウザで開けば、それで動きます。

スマホから見るときは、パソコンの IP アドレスを調べて、
スマホのブラウザで `http://192.168.○.○:8787` を開きます。

| | IPアドレスの調べかた |
|---|---|
| Mac | `ipconfig getifaddr en0` |
| Windows | `ipconfig` → 「IPv4 アドレス」 |

**パソコンの電源を切ると使えなくなります。** 現場に持ち出すなら、下の B か C にしてください。

---

## B. 現場でいつでも使う(おすすめ・無料)

インターネット上に置いて、URL を開けば誰でも使えるようにします。月額はかかりません。

### B-1. GitHub Pages を使う

このリポジトリには、`main` に入ったら自動で公開する仕掛け
(`.github/workflows/pages.yml`)がすでに入っています。やることは2つだけです。

1. **リポジトリを public にする**
   (Settings → General → いちばん下の Danger Zone → Change visibility)
   ※ private のまま Pages を使うには GitHub の有料プランが必要です。
   このアプリにパスワードもAPIキーも入っていないので、public にして困るものはありません。
2. **Settings → Pages → Source を「GitHub Actions」にする**

これで `main` にマージするたび、自動で
`https://ka1tetsu.github.io/zumen/` に反映されます。

### B-2. リポジトリを private のままにしたいとき

**Cloudflare Pages** か **Netlify** を使います。どちらも private リポジトリでも無料です。

- GitHub アカウントでログイン → このリポジトリを選ぶ
- ビルドコマンド: **なし(空のまま)**
- 公開するフォルダ: **`public`**

これだけです。`https://なんとか.pages.dev` のような URL がもらえます。

## C. スマホに「アプリとして」入れる

URL ができたら、現場で使う人のスマホに入れます。ブラウザのブックマークではなく、
**ホーム画面に追加**してください。アイコンから一発で開けて、画面も広く使えます。

| | やりかた |
|---|---|
| iPhone (Safari) | URL を開く → 下の **共有ボタン** (□に↑) → **「ホーム画面に追加」** |
| Android (Chrome) | URL を開く → 右上の **⋮** → **「アプリをインストール」** or 「ホーム画面に追加」 |

一度開いておけば、**あとは電波がなくても動きます**(写真の読み取りも含めて)。
初回だけ 10MB ほど読み込むので、**現場に行く前に Wi-Fi で一度開いておいてください。**

## 使う流れ(現場の人に渡す説明)

1. アイコンを開く
2. **「しゃしんで はかる」** を押す
3. 図面を撮る(近くで・まっすぐ・明るいところで)
4. **「すうじを よみとる」** を押して少し待つ
5. 図面の数字に ①②③… と番号がつくので、**聞かれた順にタップする**
   - 「① かべの よこはば は どれですか?」→ 幅の数字をタップ
   - 「② かべの たかさ は どれですか?」→ 高さをタップ(「よくある たかさ 2400 / 2500」も出ます)
   - これで壁が1つ増えます。次の壁も同じように選べます
6. かざり棚・間接照明は、上のボタンで切り替えて同じように選びます
   (間接照明の「展開幅」は図面に出ていないので、図を見ながら手で入れます)
7. **「けいさん する」** → ロール数が大きく出ます
8. **「よみあげ」「コピー」「いんさつ」「ほぞん」** が使えます

うまく読めないときは、**「この なかに ない → じぶんで いれる」** から手入力できます。
手入力だけでも全部の計算ができます。

## よくある困りごと

| こうなった | どうする |
|---|---|
| 数字が1つも見つからない | 図面に近づいて撮り直す。斜め・暗い・手ブレに弱いです |
| ちがう数字を選んでしまった | 一覧でその行を押すと、入力画面で直せます |
| ロール数が思っていたより多い | せってい画面で「よび(%)」「切りしろ」「材料の幅」を現場に合わせて直せます |
| 文字が小さい | 右上の「ぁあ」を押すと、3段階で大きくなります |
| 前の計算に戻したい | ホームの「きろく」から呼び出せます |
