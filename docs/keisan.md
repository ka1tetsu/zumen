# 計算のしかた(職人さん向け)

このアプリがどう数字を出しているか、全部ここに書いてあります。
納得できない数字があったら、ここを見て、**せってい**画面で変えてください。
計算そのものは `public/engine.js` の中だけにあります。

寸法はすべて **mm** で持っています。

---

## 1. 基本(かべ・てんじょう)

```
有効幅   = 材料の幅 − ジョイントの重ねしろ      (既定 920 − 20 = 900 mm)
枚数     = 切り上げ(かべの幅 ÷ 有効幅)
1枚の丈  = かべの高さ + 上下の切りしろ           (既定 100 mm)
         柄がある場合は、リピートの倍数まで切り上げ
必要な長さ = 枚数 × 1枚の丈
```

例:幅 3,600 / 高さ 2,400 のかべ
→ 枚数 4枚、丈 2,500、必要 10.0 m

**天井**は長手方向に張るものとして、短いほうの辺で枚数を、長いほうの辺で丈を取ります。

**柄合わせ(リピート)** は、せってい画面の「クロスのしゅるい」でクロスごとに入れます。
0 なら無地あつかいで、切り上げをしません。

---

## 2. 窓・ドア

既定は **引きません**。小さい開口を引くと、かえって足りなくなるためです。

せってい画面で「まど・ドアを ひく」を入れると、こう計算します。

- かべを有効幅ごとに分け、**1枚の幅がまるごと開口に入るとき**だけ、上下に分けて拾う
- 開口に少しだけかかる枚は、丈を通しで取る(実際に切り回すから)
- 残りが **150 mm 未満** の切れ端は、張らないものとして落とす
- **柄があるときは、上下に分けず通しで拾う**(柄合わせができなくなるため)

面積は、開口の面積をそのまま引いた値を出しています(のりの量の目安に使う)。

---

## 3. 飾り棚(ニッチ)

開口の内側を展開して、面ごとの切り板として拾います。

| 面 | 寸法 |
|---|---|
| 奥板 | 幅 × 高さ |
| 上端(天板) | 幅 × 奥行 |
| 下端(地板) | 幅 × 奥行 |
| 左の側板 | 奥行 × 高さ |
| 右の側板 | 奥行 × 高さ |

- それぞれに、1辺あたり **20 mm**(既定)の切りしろを四方に足します
- 足したあと、材料の幅(有効幅)の中に **長いものから順に並べて**、
  何 m の材料を切れば足りるかを出します(いわゆる取り都合。棚詰め=FFDH)
- 材料の幅より大きい面があるときは、「ジョイントが必要」と注意を出します
- 張らない面は、チェックを外せば拾いません

入隅・出隅の数も数えて出しています。**材料は少なくても、手間はかかります。**
見積りのときは、この数を見て手間を乗せてください。

---

## 4. 間接照明(コーブ・コーニス)

細長い「帯」で取るので、ふつうの壁とは計算が違います。

```
帯の幅   = 展開幅(たちあがり + そこ + みつけ) + 切りしろ(既定 30 mm)
取れる本数 = 切り捨て(有効幅 ÷ 帯の幅)
必要な長さ = 切り上げ(照明の通りの長さ ÷ 取れる本数) + 上下の切りしろ
```

例:通り 5,000 / 展開幅 250
→ 帯の幅 280、有効幅 900 から **3本** 取れる
→ 5,000 ÷ 3 = 1,667 + 100 = **約 1.8 m** で足りる

展開幅が有効幅を超えるときは、帯で取れないので、
ふつうのかべと同じ取り方(丈で拾う)に切り替えて計算します。

---

## 5. ロール数・副資材

```
発注する長さ = 必要な長さ × (1 + 予備%)        予備は既定 5%
ロール数     = 切り上げ(発注する長さ ÷ 1ロールの長さ)   既定 50 m/巻
```

品番(クロスのしゅるい)ごとに分けて集計します。

副資材は **目安** です。現場とメーカーで変わるので、せっていで直してください。

| もの | 目安 | どこで使うか |
|---|---|---|
| のり | 0.25 kg/m²(施工面積あたり) | でんぷん系のりを想定 |
| ジョイントコーク | 1本あたり 70 m | ジョイント延長(縦のジョイント + 天井際 + 巾木際) |

---

## 6. 変えられるところ(せってい画面)

- 材料の幅(92 / 95 / 106 / 137 cm)と 1ロールの長さ(50 m / 30 m)
- 柄のリピート
- 上下の切りしろ、ジョイントの重ねしろ
- 予備(%)
- 飾り棚の切りしろ、間接照明の帯の切りしろ
- まど・ドアを引くかどうか

---

## 7. 写真の読み取りについて

写真から数字を拾うところは、**スマホのブラウザの中だけ**で動いています
(Tesseract.js。通信なし・費用なし)。拾った数字は、そのままでは使いません。

- 図面は紙のあちこちに数字が散っているので、ページ解析を **SPARSE_TEXT(PSM 11)** にしている。
  ふつうの文章あつかいだと、枠の中の寸法を取りこぼす
- `3,640` → 3640、`2.4m` → 2400、`45cm` → 450、`910mm` → 910 と、すべて mm に直す
  (`public/ocr-parse.js`)
- 単位のない小数(`3.64`)は m とみなす。図面でそう書かれるため
- **100mm 未満・30,000mm 超は捨てる。** 部屋番号や縮尺("1/50")を寸法と間違えないため
- `CH=2400` のように天井高と分かるものには印をつけ、高さの候補として出す
- 読み取りの自信が 40 未満のものは捨てる
- 拾った数字は**必ず人がタップして割り当てる**。どれが幅でどれが高さかを機械に決めさせない

**読み取りは万能ではありません。数字は必ず職人の目で確かめてください。**
